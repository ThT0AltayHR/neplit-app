# Neplit AI - Android APK Build

**Paket adı:** `com.neplit.app`

## GitHub Actions ile APK Oluşturma

1. **Actions** → **Build Neplit APK** → **Run workflow** butonuna bas
2. İş bittikten sonra **Artifacts** bölümünden `neplit-apk` dosyasını indir
3. `neplit-signed.apk` dosyasını telefonuna yükle ✅

## Değiştirilenler

| Alan | Eski | Yeni |
|------|------|------|
| Paket adı | `com.replit.app` | `com.neplit.app` |
| APK adı | `com.replit.app.apk` | `com.neplit.app.apk` |

> Artık Replit uygulamasıyla çakışmaz.
