## 📱 APK İndirme & Kurulum

### GitHub Actions ile Derle (Önerilen)

```
1. Actions → Build Neplit APK → Run workflow
2. İş bitince Artifacts → neplit-apk indir
3. neplit-signed.apk → telefonuna yükle
```

### Paket Bilgileri

| Alan | Değer |
|------|-------|
| Paket Adı | `com.neplit.app` |
| Min Android | 7.0 (API 24) |
| Hedef SDK | Android 16 (API 36) |
| Versiyon | 2.193.0 |

> ⚠️ **Not:** Kurulum için telefon ayarlarından "Bilinmeyen kaynaklara izin ver" seçeneğini etkinleştirin.

## 🔧 Geliştirici Notları

- **Framework:** React Native (Expo SDK 54) + Hermes Engine

- **Bildirimler:** Firebase Cloud Messaging
- **Depolama:** Güvenli şifreli yerel depolama (expo-secure-store)
- **Fontlar:** Hack Regular, IBM Plex Sans Medium/Regular
